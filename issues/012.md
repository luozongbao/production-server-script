# Issue #012 — Auto-detect msmtp and help install .msmtprc

**Severity**: feature
**Status**: open
**Target**: v1.1.0
**File**: [setup.sh](../../setup.sh) — new section, depends on apt-installed `msmtp`

## Problem

`msmtp` is a popular lightweight SMTP client that many servers use to send mail (cron job output, monitoring alerts, etc.) without running a full MTA like Postfix. Installing `msmtp` from apt gives you the binary, but **does not** write `~/.msmtprc` — which contains the SMTP server, credentials, and TLS settings.

Admins who install `msmtp` expect `~/.msmtprc` to be created as part of the setup, but right now `setup.sh` doesn't touch it at all. Result: cron jobs fail silently, "mail" goes nowhere.

## Proposed design

Add a new section `section_msmtp` that:
1. **Detects** if `msmtp` is installed (via `command -v msmtp` or `dpkg -s msmtp`)
2. If installed:
   a. Reads SMTP config from `.env` (`MSMTP_HOST`, `MSMTP_PORT`, `MSMTP_USER`, `MSMTP_PASSWORD`, `MSMTP_FROM`)
   b. Writes `~/.msmtprc` for the `TARGET_USER` (and optionally root's `~/.msmtprc`)
   c. Sets correct permissions: `chmod 600 ~/.msmtprc`
3. If **not installed** AND `MSMTP_ENABLED=true`: install via `apt-get install -y msmtp msmtp-mta`
4. Skips silently if `msmtp` not installed and `MSMTP_ENABLED` not set

## .env variables

```bash
# Set to "true" to install msmtp and configure .msmtprc.
# If msmtp is already installed, this still triggers .msmtprc setup.
MSMTP_ENABLED=

# SMTP server settings
MSMTP_HOST=smtp.example.com
MSMTP_PORT=587
MSMTP_USER=alerts@example.com
MSMTP_PASSWORD=
MSMTP_FROM=alerts@example.com

# Optional: also write /root/.msmtprc for system cron jobs
MSMTP_ROOT_CONFIG=true
```

## CLI flags

| Flag | Behavior |
|---|---|
| `--msmtp` / `-M` | enable section |
| `--no-msmtp` | disable section |
| default | disabled (opt-in) |

Add `"msmtp"` to `OPT_IN_SECTIONS=(...)`.

## Implementation sketch

```bash
section_msmtp() {
  section "msmtp SMTP client configuration"

  # Step 1: install if requested and missing
  if [[ "${ENV[MSMTP_ENABLED]:-}" =~ ^[Tt]rue$ ]] && ! command -v msmtp >/dev/null 2>&1; then
    info "msmtp not installed — installing"
    if ! apt-get install -y -qq msmtp msmtp-mta; then
      err "apt-get install msmtp failed"
      return 1
    fi
  fi

  # Step 2: bail if msmtp still not available
  if ! command -v msmtp >/dev/null 2>&1; then
    info "msmtp not present — skipping"
    return 0
  fi

  # Step 3: collect SMTP settings
  local host="${ENV[MSMTP_HOST]:-}"
  local port="${ENV[MSMTP_PORT]:-587}"
  local user="${ENV[MSMTP_USER]:-}"
  local pass="${ENV[MSMTP_PASSWORD]:-}"
  local from="${ENV[MSMTP_FROM]:-$user}"

  if [[ -z "$host" || -z "$user" ]]; then
    if [[ "$NONINTERACTIVE" == "true" ]]; then
      err "MSMTP_HOST and MSMTP_USER are required when NONINTERACTIVE=true"
      return 1
    fi
    read -r -p "  SMTP host: " host
    read -r -p "  SMTP port [587]: " port; port="${port:-587}"
    read -r -p "  SMTP user: " user
    read -r -s -p "  SMTP password: " pass; echo
    read -r -p "  From address [$user]: " from; from="${from:-$user}"
  fi

  # Step 4: write ~/.msmtprc (per-user)
  local rcfile="$TARGET_HOME/.msmtprc"
  cat > "$rcfile" <<EOF
# Managed by production-server-script
defaults
auth           on
tls            on
tls_starttls   on
logfile        ~/.msmtp.log

account        default
host           $host
port           $port
from           $from
user           $user
password       $pass
EOF
  chown "$TARGET_USER":"$TARGET_USER" "$rcfile"
  chmod 600 "$rcfile"
  ok "Wrote $rcfile (mode 600)"

  # Step 5: optionally also configure /root/.msmtprc
  if [[ "${ENV[MSMTP_ROOT_CONFIG]:-}" =~ ^[Tt]rue$ ]]; then
    cp "$rcfile" /root/.msmtprc
    chmod 600 /root/.msmtprc
    ok "Wrote /root/.msmtprc (mode 600)"
  fi

  # Step 6: smoke test
  if [[ "${ENV[MSMTP_TEST_EMAIL_TO]:-}" =~ ^[^@]+@[^@]+$ ]]; then
    local body="From: $from\nTo: ${ENV[MSMTP_TEST_EMAIL_TO]}\nSubject: setup.sh msmtp test\n\nTest from $(hostname) at $(date)."
    if printf "$body" | msmtp "${ENV[MSMTP_TEST_EMAIL_TO]}" >/dev/null 2>&1; then
      ok "Sent test email to ${ENV[MSMTP_TEST_EMAIL_TO]}"
    else
      warn "Test email send failed — check $rcfile and ~/.msmtp.log"
    fi
  fi
}
```

## Test plan

1. Run on a system without msmtp, with `MSMTP_ENABLED=false` — section should be a no-op
2. Run on a system with msmtp pre-installed and full `.env` — `.msmtprc` is created with correct perms (`600`)
3. Run on a system without msmtp, with `MSMTP_ENABLED=true` — apt installs it, `.msmtprc` is written
4. Run with `MSMTP_ROOT_CONFIG=true` — both user and root get `.msmtprc`
5. (Optional) Send a test email with `MSMTP_TEST_EMAIL_TO`

## Acceptance criteria

- Auto-detects msmtp presence (no false positives)
- `.msmtprc` is written with **0600** perms (msmtp refuses to run with looser perms)
- Idempotent: re-running overwrites cleanly
- Optional apt-install path works
- Works in `--non-interactive` when all keys set
- Optional test email confirms SMTP auth works
