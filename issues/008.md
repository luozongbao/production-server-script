# Issue #008 — validate_hostname missing explicit return 0

**Severity**: cosmetic
**Status**: open (resolved as side-effect of #1)
**Target**: v1.1
**File**: [setup.sh:285-292](../../setup.sh#L285-L292)

## Problem

```bash
validate_hostname() {
  local h="$1"
  if [[ ${#h} -gt 253 ]]; then err "..."; return 1; fi
  if ! [[ "$h" =~ ^...regex...$ ]]; then
    err "..."
    return 1
  fi
  # <-- implicit return 0 here
}
```

Function relies on bash's implicit `return 0` at end of function. If anyone adds code after the second `if` (logging, telemetry, etc.), the return code might silently change.

## Resolution

Already fixed as part of Issue #001 fix (the regex tightening commit added explicit `return 0`).
