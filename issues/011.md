# Issue #011 — Pull and install luozongbao/server-report-script

**Severity**: feature
**Status**: open
**Target**: v1.1.0
**File**: [setup.sh](../../setup.sh) — new section

## Problem

The user maintains a companion repo at [`luozongbao/server-report-script`](https://github.com/luozongbao/server-report-script) which collects server diagnostics and reports them. Installing it manually is multi-step:

1. Clone the repo
2. Pick a release tag (or use `main`)
3. Run the installer (or copy scripts to `/usr/local/bin`)
4. Configure cron / systemd timer

`setup.sh` should automate this as an opt-in section.

## Proposed design

Add a new section `section_server_report` that, when enabled:
1. Reads `SERVER_REPORT_VERSION` from `.env` (e.g. `v1.2.3` or `latest`)
2. Downloads the **release tarball** (not a git clone — releases are immutable, smaller, no `.git` history)
3. Verifies the SHA256 checksum (if a `.sha256` asset is published alongside)
4. Extracts to `/opt/server-report-script/`
5. Runs the upstream installer if one exists (`install.sh` or `Makefile install`)
6. Symlinks the main binary to `/usr/local/bin/server-report`
7. Optionally installs a systemd timer if the upstream provides a `.service` + `.timer` unit

## .env variables

```bash
# GitHub owner/repo
SERVER_REPO="luozongbao/server-report-script"

# Version tag — "latest" resolves to the newest release, or pin like "v1.2.3"
SERVER_REPORT_VERSION=latest

# Set to "true" to install + enable systemd timer for daily reports
SERVER_REPORT_TIMER=true
```

## CLI flags

| Flag | Behavior |
|---|---|
| `--server-report` / `-R` | enable section |
| `--no-server-report` | disable section |
| default | disabled (opt-in) |

Add `"server-report"` to `OPT_IN_SECTIONS=(...)`.

## Implementation sketch

```bash
section_server_report() {
  section "Install luozongbao/server-report-script"
  local repo="${ENV[SERVER_REPO]:-luozongbao/server-report-script}"
  local ver="${ENV[SERVER_REPORT_VERSION]:-latest}"

  # Resolve "latest" → real tag via GitHub API
  if [[ "$ver" == "latest" ]]; then
    ver=$(curl -fsSL "https://api.github.com/repos/${repo}/releases/latest" \
      | grep -oP '"tag_name":\s*"\K[^"]+' | head -1)
    [[ -z "$ver" ]] && { err "Could not resolve latest release for $repo"; return 1; }
  fi

  local tarball="https://github.com/${repo}/archive/refs/tags/${ver}.tar.gz"
  local tmpdir; tmpdir=$(mktemp -d)
  local archive="$tmpdir/srs.tgz"

  info "Downloading $repo @ $ver"
  if ! curl -fsSL -o "$archive" "$tarball"; then
    err "Download failed: $tarball"
    rm -rf "$tmpdir"; return 1
  fi

  # Optional checksum verify
  if curl -fsSL -o "$archive.sha256" "${tarball}.sha256" 2>/dev/null; then
    if ! (cd "$tmpdir" && sha256sum -c srs.tgz.sha256 >/dev/null 2>&1); then
      err "Checksum mismatch — refusing to install"
      rm -rf "$tmpdir"; return 1
    fi
    ok "Checksum verified"
  else
    warn "No .sha256 asset published — skipping checksum verification"
  fi

  # Extract
  mkdir -p /opt/server-report-script
  tar -xzf "$archive" -C "$tmpdir"
  # Tarball extracts to server-report-script-<ver-no-v>/; flatten
  shopt -s dotglob
  cp -af "$tmpdir"/server-report-script-*/. /opt/server-report-script/
  shopt -u dotglob
  ok "Installed to /opt/server-report-script"

  # Run upstream installer if present
  if [[ -x /opt/server-report-script/install.sh ]]; then
    info "Running upstream installer"
    /opt/server-report-script/install.sh || warn "upstream install.sh exited non-zero"
  fi

  # Symlink main binary
  if [[ -x /opt/server-report-script/bin/server-report ]]; then
    ln -sf /opt/server-report-script/bin/server-report /usr/local/bin/server-report
    ok "Symlinked /usr/local/bin/server-report"
  fi

  # Optional systemd timer
  if [[ "${ENV[SERVER_REPORT_TIMER]:-}" =~ ^[Tt]rue$ ]]; then
    if [[ -f /opt/server-report-script/systemd/server-report.timer ]]; then
      cp /opt/server-report-script/systemd/server-report.{service,timer} /etc/systemd/system/
      systemctl daemon-reload
      systemctl enable --now server-report.timer
      ok "Enabled server-report.timer"
    else
      warn "No systemd unit shipped — skipping timer"
    fi
  fi

  rm -rf "$tmpdir"
}
```

## Test plan

1. Run with `SERVER_REPORT_VERSION=v1.0.0` — verify download + extract + symlink
2. Re-run — verify idempotent (overwrites in place, no duplicate symlinks)
3. Run with bogus version — verify graceful error, no partial install
4. Run with `SERVER_REPORT_TIMER=true` — verify timer is active (`systemctl list-timers`)

## Acceptance criteria

- Downloads from GitHub releases (not git clone)
- Optional checksum verification
- Idempotent re-installs
- Upstream `install.sh` invoked if present
- Optional systemd timer integration
- Works in `--non-interactive` mode when all `.env` keys set
